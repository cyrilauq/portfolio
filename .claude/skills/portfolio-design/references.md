# Reference portfolios

Notes collected on 2026-11-16. They describe what to borrow and what to avoid, not designs to copy.

## Reviewed

- **https://mbitu-portfolio.vercel.app/**: one-page anchor nav (Home, About, Skills, Projects, Contact).
  Hero has name, role and one CTA ("Let's Connect") plus social icons. Projects are cards with a screenshot,
  repo and live links, and tags, plus filter tabs (All / Web Dev / AI/ML / Mobile). Education is a timeline.
  Certifications are shown as images. "What Excites Me" interest cards add a personal touch.
  - Borrow: project filters, repo and live links on every project, CV download, visible proof (certificates).
  - Avoid: skill percentage bars, boilerplate footer (Quick Links/Services/Newsletter pointing to `#`),
    stale copyright year, typos, emoji in copy.

- **Silkhom article: "Portfolio de développeur web, six exemples parfaitement réalisés"**
  (https://www.silkhom.com/portfolio-de-developpeur-web-six-exemples-parfaitement-realises/, 2020)
  - https://mattfarley.ca/: minimal, airy, coherent colours. The offer is clear immediately, client
    references are at the bottom, contact form and socials. One page is enough.
  - https://www.pierreburel.com/: a single page written as code. Projects, experience, skills and socials
    all fit on it. Simple, effective, coherent.
  - https://www.raoul-gaillard.com/: interactive geometric shapes react to the mouse. Each project has its own
    palette, and generous whitespace keeps navigation and reading easy.
  - "Jack" (no link): dark theme with one bright accent for contrast, discreet code snippets as personality,
    mobile-friendly vertical nav, project mosaic with hover states.
  - https://caferati.me/: optional mini-game behind a CTA, vertical social bar, **projects filterable by
    technology**, "Labs" section for demos and articles.
  - https://peteroravec.com/: game-like world built with Phaser, with a map so visitors don't get lost.
    Impressive, but heavy; only for a deliberate creative direction.
  - Implied criteria: clear offer, coherent identity, easy navigation (including mobile), social proof and
    contact, well-presented projects, and creativity that serves the content.
